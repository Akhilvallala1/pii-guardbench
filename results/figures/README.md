# figures

Generated by `python scripts/make_figures.py` (needs the `figures` extra: `pip install -e ".[figures]"`) from
`results/pgb-v1.0-{clean,hard,control}.json`. Every point is one non-mock adapter (labeled). **Mocks
(`mock-leaky`, `mock-redact`) are excluded.** Error bars are cluster-bootstrap 95% CIs (clusters = `template_id`)
on both axes, except where noted. The red step line is the Pareto frontier: lower-left is better, a point is on
it if no other system has both lower x and lower y. Output is deterministic (fixed data, Agg backend, no
timestamp metadata).

| File | x axis | y axis | Color |
| --- | --- | --- | --- |
| `a_clean_leak_vs_raw_fpr.png` | raw control FPR (blocked, or any token deleted/replaced) | clean normalized leak | clean blocked rate |
| `b_clean_inscope_leak_vs_contract_fpr.png` | contract-aware control FPR | clean in-scope prompt leak (Wilson 95%: no cluster CI is stored for in-scope leak) | clean blocked rate |
| `c_hard_leak_vs_raw_fpr.png` | raw control FPR | hard normalized leak | clean blocked rate |
| `d_clean_leak_vs_clean_block_rate.png` | clean blocked rate (share of PII prompts blocked; Wilson 95%, an explicit cost axis) | clean normalized leak | none |

With only 12 PII templates and 8 control templates per layer the intervals are wide; overlapping points are not
established rankings.
