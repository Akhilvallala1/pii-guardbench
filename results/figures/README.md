# figures

Generated by `python scripts/make_figures.py` (needs the `figures` extra: `pip install -e ".[figures]"`) from
`results/pgb-v1.0-{clean,hard,control}.json`. Each figure is written as PNG (300 dpi) and PDF. Every point is one
non-mock adapter. **Mocks (`mock-leaky`, `mock-redact`) are excluded.** All error bars, on both axes, are
cluster-bootstrap 95% CIs over templates (2,000 iterations, seed 0; 12 PII templates per layer, 8 control templates).
The red step line is the Pareto frontier: lower-left is better, and a point is on it if no other system is at
least as good on both axes and strictly better on one (weak dominance). When the front is a single point (as in b),
there is no line: that point is ringed in red and the legend reads "Pareto front (single point)". Output is deterministic (fixed data, Agg backend, no timestamp metadata).

Labels use a fixed short-name map (`presidio`, `pres-all@.4`, `pres-n6@0`, `pres-n6@.4`, `nemo-mask`, `nemo-all`,
`nemo-det`, `piiguard`, `pg-pres` = piiguard-pgpresidio, `union` = piiguard-union-presidio, `gliner`, `llm-anon`,
`llm-blk`). Systems within 0.01 of each other on both axes share one merged label (for example
`pres-n6@0/@.4, nemo-mask`). Labels are placed deterministically: crowded points get a callout column with leader
lines, the rest are placed greedily over candidate offsets. Each candidate is checked with the renderer for overlap
with other labels, markers, the Pareto line and the legend. `tests/test_contract_fpr_layers.py` asserts that no two
label bounding boxes overlap in any generated figure.

## Main text (single column, 3.3 x 2.6 in, 8 pt)

**(b) `b_clean_inscope_leak_vs_contract_fpr`.** Clean-layer in-scope prompt leak (leak on the categories each
system is configured for) vs contract-aware control FPR. y error bars: prompt-level cluster-bootstrap CI of in-scope
leak (`in_scope.prompt_leak_cluster_bootstrap`). x error bars: cluster-bootstrap CI of contract-aware FPR.
Color: **clean-layer** blocked rate. The axes are zoomed to the points. Small grey arrowheads at the top or right
edge mark CIs that extend past the plotted range (`gliner`: in-scope leak up to 0.477 and contract FPR up to 0.855).

**(d) `d_clean_leak_vs_clean_block_rate`.** Clean normalized leak vs clean blocked rate (share of PII prompts
blocked, an explicit cost axis). y error bars: cluster-bootstrap CI of leak. x error bars: cluster-bootstrap CI of
blocked rate (`blocked_rate_cluster_bootstrap`). No color.

## Appendix (6.3 x 3.6 in, 9 pt)

**(a) `a_clean_leak_vs_raw_fpr`.** Clean normalized leak vs raw control FPR. Both error bars are cluster-bootstrap
CIs. Color: **clean-layer** blocked rate.

**(c) `c_hard_leak_vs_raw_fpr`.** Hard-layer (obfuscated) normalized leak vs raw control FPR. Both error bars are
cluster-bootstrap CIs. Color: **hard-layer** blocked rate (`nemo-det` 0.080, `llm-blk` 0.100, all others 0). It is
not the clean-layer rate.

With only 12 PII templates and 8 control templates per layer the intervals are wide. Points whose intervals overlap
are not established rankings.
